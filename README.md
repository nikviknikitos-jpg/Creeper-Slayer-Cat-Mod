# CreeperSlayerCatMod (Fabric 1.20.1)

## Механика
- Прирученные коты-охотники сами убивают криперов, разрывая их на две половинки.
- Предмет `creepercat:feline_mutagen` («Сфера Первородного Кота») выдаётся только командой:
  `/give @s creepercat:feline_mutagen` или `/givecatcore`.
- ПКМ сферой превращает игрока в кота с 3 стадиями эволюции.
- Стадии открываются за разрывание криперов в кошачьем облике (ЛКМ/ПКМ вблизи).

## Сборка
JDK 17, Gradle 8.8. GitHub Actions workflow прилагается.
